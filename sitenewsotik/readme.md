## 📖 Описание

**СайтыСотика** — это локальный или хостинговый хаб, объединяющий все ключевые проекты стримера Сотика в одном месте:

- 🏠 [СайтСотика](site-sotik/) — основной сайт
- 💰 [ДонатыСотика](donate-sotik/) — страница поддержки
- 🎯 [АукционСотика](auction-sotik/) — виртуальный аукцион (например, за дом)

Каждая карточка — кликабельная, с анимацией наведения и плавным переходом на соответствующий проект.

## 🧩 Функционал

| Карточка        | Назначение                     | Переход в папку       |
|----------------|-------------------------------|------------------------|
| `СайтСотика`   | Основной сайт стримера         | `site-sotik/`          |
| `ДонатыСотика` | Страница донатов               | `donate-sotik/`        |
| `АукционСотика`| Аукцион за дом или призы       | `auction-sotik/`       |

> Все переходы реализованы через JavaScript по `data-title`.

---

## ⚙️ Как работает

Клик по карточке обрабатывается через `dataset.title`:

```js
switch(title) {
  case 'СайтСотика':
    window.location.href = 'site-sotik/';
    break;
  case 'ДонатыСотика':
    window.location.href = 'donate-sotik/';
    break;
  case 'АукционСотика':
    window.location.href = 'auction-sotik/';
    break;
}
```

## 🚀 Запуск

1. Скачайте или склонируйте репозиторий
2. Убедитесь, что структура папок корректна
3. Откройте `sitenewsotik/index.html` в браузере

> 🔹 Работает **локально** — не требует сервера  
> 🔹 Поддерживает **автономный запуск** (через `file://`)

## 🎨 Дизайн

- **SVG-иконки** — векторные, масштабируются без потерь
- **Неоновые градиенты** — через `<linearGradient>` и `filter: url(#glow)`
- **Анимации** — `:hover` с `transform` и `transition`
- **Тёмная тема** — стильная и удобная для глаз
