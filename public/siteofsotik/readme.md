# СайтСотика — Документация проекта

## Общее описание

**СайтСотика** — это веб-платформа, разработанная для поддержки стримера Сотика (fsbsotik) и организации взаимодействия с его аудиторией. Проект объединяет в себе **видеоплеер Twitch**, **чат в реальном времени** и **систему донатов** с несколькими способами оплаты. Основная цель — создать удобный и безопасный интерфейс для зрителей, позволяющий им общаться, поддерживать стримера финансово и получать обратную связь.

Сайт размещён по домену `сайтсотика.рф` (в IDN-формате) и оптимизирован под русскоязычную аудиторию. Он использует современные веб-технологии, включая **HTML5**, **CSS3**, **JavaScript (ES6+)** и **Supabase** в качестве бэкенда для хранения сообщений и статистики донатов.

---

## Архитектура проекта

Проект организован в виде одностраничного приложения (SPA), где вся логика реализована на клиентской стороне. Серверная часть отсутствует — вместо этого используется **Supabase**, который предоставляет:

- Хранилище данных (PostgreSQL)
- Аутентификацию (не используется в текущей версии)
- Реальное время (не используется напрямую)
- API для работы с базой данных

## Система донатов

Одна из ключевых функций сайта — возможность поддержать стримера финансово.

### Этапы доната

1. Пользователь включает переключатель "Донат"
2. Появляется выбор способа оплаты
3. Выбирается банк или платёжная система
4. Указывается сумма
5. Подтверждается оплата
6. Сообщение отправляется как донат

### Доступные способы оплаты

- **ЮMoney (ЮМани)**
- **СБП (Система быстрых платежей)**
- **Тинькофф**
- **Сбербанк**
- **ВТБ**
- **Другое (вручную)**

### Интерфейс выбора суммы (ЮMoney)

```html
<div class="ym-grid">
    <button class="ym-btn" data-sum="50">50 ₽</button>
    <button class="ym-btn" data-sum="100">100 ₽</button>
    <button class="ym-btn other" data-sum="custom">Своя сумма</button>
</div>
```

При выборе "Своя сумма" появляется поле ввода.

### QR-коды

Для банков (СБП, Тинькофф, Сбер, ВТБ) используются **QR-коды**, по которым можно отсканировать и оплатить. После оплаты пользователь нажимает "Оплатил".

## Работа с Supabase

Supabase используется как бэкенд для хранения сообщений чата и статистики донатов.

### Подключение

```js
const supabaseUrl = 'https://xdohisilunbnfqbuglwi.supabase.co';
const supabaseAnonKey = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
const supabase = supabase.createClient(supabaseUrl, supabaseAnonKey);
```

> ⚠️ **ВАЖНО**: В текущем коде используется **пример ключа**. В продакшене необходимо заменить его на настоящий `anon` ключ из настроек Supabase.

### Таблица `chat_messages`

Ожидается, что в базе есть таблица с такой структурой:

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | `bigint` | Уникальный ID |
| `name` | `text` | Имя отправителя |
| `surname` | `text` | Фамилия (или пусто) |
| `message` | `text` | Текст сообщения |
| `is_donate` | `boolean` | Это донат? |
| `amount` | `integer` | Сумма доната (если есть) |
| `inserted_at` | `timestamp` | Время отправки |

### Основные операции

#### Загрузка сообщений

```js
async function loadMessages() {
    const { data, error } = await supabase
        .from('chat_messages')
        .select('name, surname, message, is_donate, amount')
        .order('inserted_at', { ascending: true });
    // ... добавление в DOM
}
```

#### Отправка сообщения

```js
async function sendToSupabase(data) {
    const { error } = await supabase
        .from('chat_messages')
        .insert([{
            name: data.name,
            surname: data.surname,
            message: data.message,
            is_donate: data.isDonate,
            amount: data.amount
        }]);
}
```

## Проблемы и ограничения

### 1. Безопасность Supabase

- Использование `anon` ключа на клиенте **небезопасно**
- Любой может читать и писать в таблицу
- Решение: использовать **Row Level Security (RLS)** в Supabase

### 2. Отсутствие валидации

- Нет проверки на спам, флуд, XSS
- Нет ограничения на длину сообщений
- Нет защиты от ботов

### 3. Жёстко заданные суммы

- Для QR-платежей сумма всегда 100 ₽
- Нет возможности указать сумму при оплате по QR

### 4. Нет подтверждения оплаты

- Пользователь нажимает "Оплатил", но система **не проверяет**, оплачено ли на самом деле
- Это можно обойти

### 5. Нет аутентификации

- Все пользователи анонимны
- Нет защиты от подмены имени

## Возможные улучшения

### 1. Внедрение RLS в Supabase

```sql
-- Включить RLS на таблице
ALTER TABLE chat_messages ENABLE ROW LEVEL SECURITY;

-- Политика: только чтение
CREATE POLICY "Enable read access" ON chat_messages
FOR SELECT USING (true);

-- Политика: только вставка
CREATE POLICY "Enable insert access" ON chat_messages
FOR INSERT WITH CHECK (true);
```

### 2. Добавить капчу

Использовать **hCaptcha** или **reCAPTCHA** перед отправкой сообщения.

### 3. Динамические QR-коды

Генерировать QR-коды с указанной суммой (например, через API ЮMoney или СБП).

### 4. WebSockets для реального времени

Вместо перезагрузки страницы — использовать **Supabase Realtime** для мгновенного обновления чата.

### 5. Хранение статистики

Создать отдельную таблицу `donate_stats` и обновлять её при каждом донате.

### 6. Поддержка анонимных донатов

Добавить галочку "Остаться анонимным".

### 7. Уведомления

Добавить звуковое оповещение при новом донате.

## Установка и развёртывание

### 1. Настройка Supabase

1. Создайте проект на [supabase.com](https://supabase.com)
2. Создайте таблицу `chat_messages`:

```sql
CREATE TABLE chat_messages (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    surname TEXT,
    message TEXT NOT NULL,
    is_donate BOOLEAN DEFAULT FALSE,
    amount INTEGER,
    inserted_at TIMESTAMPTZ DEFAULT NOW()
);
```

3. Включите RLS
4. Скопируйте `anon` ключ и URL

### 2. Обновление кода

Замените в `index.html`:

```js
